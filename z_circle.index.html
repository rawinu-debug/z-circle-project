ผลลัพธ์ผู้รอดชีวิตคนสุดท้าย: -
ลำดับการยิงสกัดและการติดเชื้อเสียชีวิตตาม รอดชีวิต: 9/9 คน
สูตรฟังก์ชันเวียนเกิดฉบับสมบูรณ์ (ตามเล่มรายงาน)
  • • กรณี n เป็นจำนวนคู่: Z(n) = 0 (ไม่มีผู้รอดชีวิต)
  • • กรณี n เป็นจำนวนคี่: Z(n) = (Z(n-2) + 3) (mod n)
  • โดยที่ Z(1) = Z(3) = 1 (หากหารลงตัวได้เศษ 0 ให้แทนด้วย n)
  • • กรณีผู้เริ่มเล่นตำแหน่ง S ใด ๆ (n คี่): Z(n, S) = (Z(n) + S - 1) (mod n)
ลำดับการลดรูปฟังก์ชันเวียนเกิดสำหรับกรณีนี้:

กติกาและสูตรคณิตศาสตร์ (อ้างอิงตามเล่มรายงานโครงงาน)

นิยามตัวแปร เงื่อนไขการเดินเกม และสูตรฟังก์ชันเวียนเกิดฉบับสมบูรณ์ (บทที่ 1, บทที่ 3 และบทที่ 4)

1. นิยามของตัวแปรและสัญลักษณ์

  • n แทน จำนวนผู้รอดชีวิตเริ่มต้นทั้งหมด (n ∈ ℤ⁺, n ≥ 2)
  • S แทน ตำแหน่งของผู้เล่นที่เริ่มยิงเป็นคนแรก (S ∈ {1, 2, 3, ..., n})
  • K แทน ตำแหน่งของผู้เล่นที่ถูกยิงสกัดในแต่ละรอบ (K คือผู้เล่นคนถัดไปที่มีชีวิตอยู่ตามเข็มนาฬิกาจากตำแหน่ง S)
  • Z(n) แทน ฟังก์ชันหาตำแหน่งของผู้รอดชีวิตคนสุดท้าย เมื่อมีผู้เล่น n คน และคนที่ 1 เป็นผู้เริ่มเล่น
  • Z(n, S) แทน ฟังก์ชันหาตำแหน่งของผู้รอดชีวิตคนสุดท้าย เมื่อมีผู้เล่น n คน และคนที่ S เป็นผู้เริ่มเล่น

2. กติกาและเงื่อนไขของเกม

  • การจัดวาง: ผู้รอดชีวิตจำนวน n คน ยืนเป็นวงกลมในตำแหน่งหมายเลข 1, 2, 3, ..., n เรียงตามเข็มนาฬิกา
  • การเดินเกม: ดำเนินไปในทิศทางตามเข็มนาฬิกา ผู้เล่นที่ถึงตาเดิน (ตำแหน่ง S) ต้องยิงสกัดผู้เล่นคนถัดไปที่มีชีวิตอยู่ (ตำแหน่ง K) ทันที
  • เงื่อนไขการเสียชีวิตตาม: เมื่อผู้เล่นตำแหน่ง K ถูกกำจัด ร่างของซอมบี้จะระเบิดเชื้อพิษ ทำให้ผู้เล่นที่มีชีวิตอยู่คนถัดไปตามเข็มนาฬิกา (ตำแหน่ง K+1) เสียชีวิตตาม 1 คนต่อ 1 ตา (ไม่มีการตายต่อเนื่องแบบโดมิโน)
  • ตาเดินถัดไป: ผู้รอดชีวิตคนถัดไปตามเข็มนาฬิกาที่ยังมีชีวิตอยู่จะรับหน้าที่ยิงสกัดในรอบถัดไป วนไปเรื่อย ๆ จนกว่าจะเหลือผู้รอดชีวิต 1 คน หรือเสียชีวิตทั้งหมด

3. สูตรฟังก์ชันเวียนเกิดฉบับสมบูรณ์

กรณีจำนวนผู้เล่นเริ่มต้น n เป็นจำนวนคู่:
Z(n) = 0
กล่าวคือ ไม่มีผู้รอดชีวิตเหลืออยู่เลยเมื่อจบเกม
กรณีจำนวนผู้เล่นเริ่มต้น n เป็นจำนวนคี่:
Z(n) = (Z(n-2) + 3) (mod n)
โดยที่ Z(1) = Z(3) = 1 (ในระบบเลขคณิตมอดุโลของโครงงาน หากหารลงตัวแล้วได้เศษเป็น 0 ให้แทนตำแหน่งผู้รอดชีวิตเป็นหมายเลข n เพราะไม่มีเก้าอี้หมายเลข 0)
กรณีขยายผลสู่ผู้เริ่มเล่นตำแหน่งใด ๆ S:
Z(n, S) = (Z(n) + S - 1) (mod n)
สำหรับกรณี n เป็นจำนวนคี่ (หากเศษเป็น 0 ให้เป็นตำแหน่งที่ n) และหาก n เป็นจำนวนคู่ Z(n, S) = 0

ตารางสรุปผลลัพธ์เปรียบเทียบ (n = 2 ถึง 20 เมื่อผู้เริ่มเล่น S = 1)

คลิกที่ช่องใด ๆ ในตารางเพื่อโหลดค่า n นั้นเข้าสู่สนามจำลองทันที (สังเกตจุดเปลี่ยนสำคัญที่ n = 15 ซึ่งได้คำตอบคือ 10)

* กรณี n เป็นคู่ Z(n) = 0 (ไม่มีผู้รอดชีวิต)
